FLIRC Remote Control Setup & Mapping

The FLIRC USB Receiver lets you use any standard infrared (IR) TV remote control with FieldStation42. When configured, remote keypresses control channel tuning, audio volume, muting, and direct channel entry.

Required Remote Key Mappings (FLIRC GUI)

TV Remote Button FLIRC GUI Key Target Action Executed
CH ▲ (Channel Up) PageUp / Up Arrow Tune next channel
CH ▼ (Channel Down) PageDown / Down Arrow Tune previous channel
VOL + (Volume Up) VolumeUp / + Increase audio volume
VOL - (Volume Down) VolumeDown / - Decrease audio volume
MUTE AudioMute / m Toggle audio mute
0 – 9 (Numeric Pad) 0 – 9 Direct channel number tuning
GUIDE / MENU g or G Jump to TV Guide channel

Fix Linux Permission (Required for Background Listener)

By default, Linux limits reading /dev/input/event* to root. Choose one of the following commands in your terminal to grant read permission:

⚡ Option A: Instant Fix (No logout required) 
echo 'SUBSYSTEM=="input", ATTRS{idVendor}=="20a0", ATTRS{idProduct}=="0001", MODE="0666"' | sudo tee /etc/udev/rules.d/99-flirc.rules && sudo udevadm control --reload-rules && sudo udevadm trigger
Option B: Add User to Input Group (Requires logout/login) 
sudo usermod -aG input $USER
